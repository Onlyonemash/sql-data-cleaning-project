# SQL Data Cleaning Project

## Project Overview
This project focuses on cleaning and transforming raw data using SQL. 
The dataset contained duplicates, null values, inconsistent formatting, and unnecessary columns. 
SQL techniques were used to improve data quality and prepare the data for analysis.

## Tools Used
- SQL
- MySQL Workbench
- GitHub

## Skills Demonstrated
- Data Cleaning
- SQL Queries
- CTEs
- Window Functions
- Removing Duplicates
- Handling Null Values
- Data Standardisation

## Data Cleaning Process
1. Removed duplicate records
2. Standardised date formats
3. Handled null and blank values
4. Split and cleaned columns
5. Removed unnecessary columns
